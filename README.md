# 健康報告互動網頁

## 專案說明

這是一個互動式健康檢查報告分析網頁，專為您的健康檢查數據設計。

### 功能特色

- 📊 **數據分析**：詳細分析您的健康檢查異常項目
- 📋 **每日任務**：可勾選的待辦事項清單，自動保存進度
- 📈 **進度追蹤**：視覺化顯示您的健康改善進度
- 🔮 **效果預覽**：了解堅持努力後的預期改善效果
- 📱 **手機友善**：完美適配手機瀏覽，極強互動性

### 健康重點涵蓋

1. **脈搏過緩** (56 bpm) - 原因分析與改善建議
2. **雙側輕度腎水腫** - 注意事項與追蹤建議
3. **尿液比重偏低** (1.004) - 飲水習慣調整
4. **血壓偏低** (99/55) - 日常注意事項
5. **尿酸接近高限** (6.0) - 飲食調整建議

### 使用方法

1. 點擊卡片查看詳細分析
2. 勾選每日任務清單
3. 查看進度條追蹤改善情況
4. 點擊時間軸了解各階段的預期效果

### 技術資訊

- 純 HTML/CSS/JavaScript 實現
- 使用 LocalStorage 保存任務進度
- 響應式設計，支援手機與桌面
- 奶油色系溫暖視覺風格
