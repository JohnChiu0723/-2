# 龍蝦網站測試 2 - 健康報告互動網頁

一個精美的互動式手機網頁，用於展示和分析健康檢查報告。

## 功能特點

- 📊 互動式健康數據展示
- 💡 詳細的數據分析與改善建議
- ✅ 每日任務清單追蹤
- 📈 進度追蹤系統
- 🔮 預期效果時間軸
- 📱 手機優化的響應式設計

## 健康報告重點

根據台南市立醫院 2026/09/21 的檢查結果：

1. 脈搏過緩 (56 bpm)
2. 兩側輕度腎水腫
3. 尿液比重偏低 (1.004)
4. 血壓偏低 (99/55)
5. 尿酸接近高限 (6.0)

## 技術 stack

- HTML5
- CSS3 (漸變色、動畫、響應式設計)
- 純 JavaScript (無框架依賴)
- LocalStorage (進度儲存)

## 使用說明

1. 點擊任一健康卡片查看詳細分析
2. 勾選每日任務清單以追蹤進度
3. 查看進度條了解整體改善狀況
4. 瀏覽時間軸預見未來改善效果
